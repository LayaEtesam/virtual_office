# Virtual Office

Welcome to the **Virtual Office** repository! This project is designed to provide a virtual workspace solution for teams and individuals, enabling seamless collaboration and productivity in a virtual environment.

## Features
- **Real-Time Communication**: Chat, video calls, and screen sharing capabilities.
- **Task Management**: Create, assign, and track tasks with ease.
- **Document Sharing**: Upload and share files securely.
- **Virtual Rooms**: Customizable spaces for teams and departments.

## Installation
To run this project locally, follow these steps:

### Prerequisites
- Python 3.8 or later
- Node.js 16.x or later
- A modern web browser (e.g., Chrome, Firefox)

### Steps
1. Clone this repository:
   ```bash
   git clone https://github.com/LayaEtesam/virtual_office.git
   ```

2. Navigate to the project directory:
   ```bash
   cd virtual_office
   ```

3. Install backend dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Install frontend dependencies:
   ```bash
   cd frontend
   npm install
   ```

5. Run the backend server:
   ```bash
   python manage.py runserver
   ```

6. Run the frontend server:
   ```bash
   cd frontend
   npm start
   ```

7. Open your browser and go to `http://localhost:3000` to access the application.

## Usage
- Register an account or log in with existing credentials.
- Create or join a virtual room.
- Start collaborating with your team using the available features.
